# MultiHunt — downloads

Arquivos oficiais do **MultiHunt** (Windows). O código do aplicativo não fica aqui.

**Baixar a versão mais recente para Windows:**
https://github.com/andredille/multihunt-releases/releases/latest/download/MultiHunt.exe

- É um programa portátil: basta abrir o `MultiHunt.exe`, sem instalar.
- Ao abrir, ele se atualiza sozinho quando há versão nova.
- É preciso uma conta MultiHunt (gratuita ou registrada): https://multihunt.lovable.app

Cada versão traz também `MultiHunt-<versão>.bundle.json`, o pacote de atualização que o próprio app baixa, e `SHA256SUMS.txt`, para conferir os arquivos.

MultiHunt é um aplicativo independente, sem vínculo com o Huntera, com a CipSoft ou com outros jogos citados.
